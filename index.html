About

Building what I love

I'm an Android developer from Ahmedabad, Gujarat, finishing up my B.E. in Computer Engineering. I specialize in native Android development, focusing on building high-performance, responsive user interfaces using **Kotlin** and **Jetpack Compose**.

My development philosophy centers around clean, scalable code. I build using standard **MVVM architecture**, using **Coroutines** & **StateFlow** for fluid async operations, and **Hilt** for robust dependency injection.
