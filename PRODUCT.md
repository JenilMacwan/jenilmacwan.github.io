# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Recruiters, Hiring Managers, and Tech Leads. They are evaluating candidates for Android Developer roles or internships and need to quickly assess technical competence and shipped projects.

## Product Purpose
A portfolio website to showcase Jenil Macwan's Android development skills, education, and shipped projects to land a role in Android development.

## Positioning
Native Android apps built screen by screen. Focuses on production-grade Kotlin, Jetpack Compose, clean MVVM architecture, and reactive data handling.

## Operating Context
Viewed in web browsers (desktop and mobile) by professionals quickly scanning for relevant technical skills, code quality (via GitHub links), and real-world project capability.

## Capabilities and Constraints
- Static HTML/CSS/JS frontend.
- Must remain fast, responsive, and easy to scan.
- Includes a dark/light mode toggle.

## Brand Commitments
- Professional, tech-focused, and clean aesthetic.
- "JM" brand mark.
- Primary theme color: #2F5D50.

## Evidence on Hand
- Projects: Pitwall (Android app), F1Companion API (Backend API), DocShare (Android app).
- Technical skills: Kotlin, Jetpack Compose, MVVM, Retrofit, Room DB, Firebase, etc.
- Education: B.E. Computer Engineering, Diploma in IT.

## Product Principles
1. **Show, Don't Tell**: Let the shipped projects and architectural choices demonstrate competence.
2. **Native Focus**: Emphasize native Android development paradigms (Compose, Kotlin, MVVM).
3. **Scannability**: Ensure recruiters can find key skills and project links instantly.
